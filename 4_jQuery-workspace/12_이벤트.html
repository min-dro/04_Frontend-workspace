이벤트 핸들러 jQuery 연결 방법 종류

* 방법1. 이벤트 메소드를 통한 연결

        [ 표현법 ]

        $("선택자").이벤트메소드(function() {

            해당 요소에 해당 이벤트 발생 시 실행할 내용;
        });

        - 이벤트메소드 종류
        클릭이벤트 : click();
        마우스엔테이벤트 : mouseenter();
        마우스아웃이벤트 : mousout();
        ...

클릭해보세요



* 방법2. on 메소드를 이용한 방법

        [ 표현법 ]

        $("선택자").on("이벤트명", function() {

            해당 요소에 해당 이벤트 발생 시 실행할 내용
        });

마우스 클릭 및 올려보세요



* 방법3. 타겟의 상위요소를 선택 후 on 메소드를 이용하는 방법

        [ 표현법 ]

        $("상위요소선택자").on("이벤트명", "하위요소선택자", function() {

            선택된 상위요소 안에 존재하는 하위요소에 대한 이벤트를 걸어주는 것!!
            해당 하위 요소에 해당 이벤트가 발생했을 때 실행할 내용;
        });

        - 타겟을 선택하는게 아니라 타겟의 상위요소를 선택하는것임!!

* 일회성 이벤트

        - 이벤트를 단 한번만 연결할 때 사용

        [ 표현법 ]

        $("선택자").one("이벤트명", function() {

            이벤트 발생 시 실행할 내용;
        });
단 한번만 실행할 것!!


* 키보드 관련 이벤트

-keydown / keypress : 키가 눌려질 때 발생하는 이벤트
keydown : 키보드의 모든 키에 다 해당됨
keypress : 키보드의 평선키 (F1 ~ F12), 기능키, 한글 제외한 나머지 키가 눌려질 때에만 해당됨
- keyup : 키가 떼어질 때 발생하는 이벤트

* 입력양식 관련 이벤트

- focus : 입력양식에 초점이 맞춰졌을 때 발생하는 이벤트
- blur : 입력양식으로부터 초점을 잃을 때 발생하는 이벤트
- change : 입력양식에 입력한 데이터의 내용이 변경될 때 발생하는 이벤트
